What it does

On a Mac, plugging a Switch 2 Pro Controller into USB-C leaves it asleep, and WoW won't pick it up on its own. PadWake sits in your menu bar and takes care of the whole setup.

Wakes automatically
Plug in your controller over USB-C and it wakes up right away with your chosen player light on.
Fixes Mac detection
Applies the macOS setting WoW needs so the controller actually shows up in-game.
Right buttons & back paddles
Shows X, Y, A, and B in the same layout as the controller in your hands, and enables the GL, GR, and C buttons.
Sets up your skills & quests
Includes a small WoW addon for all 9 classes that places skills for your level and talents, and fixes quest dialogs so A accepts and B goes back.

How to install

git clone https://github.com/mindthelatency/padwake.git
cd padwake
make install-app

Installs PadWake into Applications and opens it in your menu bar. Click Setup inside the app, then restart Battle.net once.

Type /padwake apply in WoW chat to set up your buttons, back paddles, quest dialogs, and skills. Run /padwake bars anytime you level up.

Prefer not to run the menu-bar app? Build the command-line tool and install the WoW files directly from Terminal.
