Built for one job — done end to end

Generic macOS controller tools stop at the USB wake packet and leave you fighting macOS's SDL2 veto, backwards Xbox glyphs, dead rear paddles, and empty action bars. PadWake handles every layer of playing World of Warcraft: Forever with a Switch 2 Pro Controller on macOS.

USB-C wake & SDL2 veto fix
Event-driven IOKit hotplug wakes 057E:2069 automatically with ~0% idle CPU, and sets SDL_JOYSTICK_MFI=0 so WoW's embedded SDL2 backend stops vetoing the native USB HID stream.
Exact Switch 2 diamond & paddles
Pairs positional SDL2 mapping with WoW's "labelStyle": "Reverse" so X (Top), Y (Left), A (Right), and B (Bottom) match your hands in both position and printed glyph — plus native bindings for rear paddles GL, GR, C, and Capture.
Level- & spec-aware Forever crossbars
The bundled PadWakeProfiles addon scans your spellbook and talent tree, populates WoW: Forever's native ZR/ZL/ZL+ZR crossbar slots across all 9 classes (with Stealth/Stance/Form paging and first-shift prompts), and sets DialogueUI to Switch mode so A accepts quests and B exits.
Zero dependencies, no sudo
Pure C11 IOKit + SwiftUI with no DriverKit extensions, no virtual-HID entitlements, no Homebrew, and no sudo. Compile locally in seconds with Apple's built-in Command Line Tools.

Install & play in 60 seconds

git clone https://github.com/mindthelatency/padwake.git
cd padwake
make install-app

Builds a Universal Binary, installs /Applications/PadWake.app, and opens it in your menu bar. Click Setup in the WoW: Forever Readiness card and restart Battle.net once.

Run /padwake apply in WoW: Forever chat to configure class CVars, GL/GR/C macros, DialogueUI Switch mode, and your level- & spec-aware ZR/ZL/ZL+ZR crossbar.

Compiles the standalone IOKit CLI, installs WoW: Forever mappings + PadWakeProfiles, and optionally installs a background LaunchAgent.
